# PWA 홈 화면 설치 가이드 (재사용용)

처음 정리: 2026-10-16, kim-minji(인계장) 1.2.0~1.2.2. 근거는 학원 홈페이지(choisci-homepage `InstallAppButton.tsx`)와 실제 안드로이드 휴대폰 문제 해결 기록이에요.
이 스킬만 따르면 앱마다 같은 설명을 반복하지 않아도 돼요.

## 0. 먼저 확인할 것
| 번호 | 질문 | 왜 |
|---|---|---|
| 1 | 앱이 기록을 **기기 안에 저장**하나? (IndexedDB·localStorage) | 그렇다면 아이폰은 사파리에서 적은 기록이 설치한 앱으로 **옮겨지지 않아요** → 3-4 「설치 먼저」 화면 필요 |
| 2 | 같은 도메인(예: `아이디.github.io`)에 다른 PWA가 있나? | 같은 주소 아래 앱들은 **저장 공간을 같이 써요**. "사이트 데이터 지우기"를 안내하면 다른 앱 기록까지 지워져요. 그러니 이 방법은 안내하지 않아요 |
| 3 | 배포 주소가 https인가? | 설치·서비스워커·Web Crypto 모두 https에서만 작동해요 (GitHub Pages는 Enforce HTTPS 켜기) |

## 1. manifest 점검표
| 번호 | 항목 | 규칙 |
|---|---|---|
| 1 | `id` | **처음부터 고정값으로 넣고 절대 바꾸지 않기**. 예: `"/레포이름/?app=이름"`. 없으면 start_url이 id가 돼요. 설치가 꼬였을 때 딱 한 번만 바꾸고 ADR에 적어요(5번 참고) |
| 2 | `start_url`, `scope` | `"./"` 상대경로 (GitHub Pages 프로젝트 주소에 맞게) |
| 3 | `display` | `"standalone"` |
| 4 | `icons` | 192·512 PNG `purpose:"any"` + 512 `purpose:"maskable"`(가장자리 20% 여백) + iOS용 `apple-touch-icon` 180 PNG (`<link rel="apple-touch-icon">`) |
| 5 | `description` + `screenshots` | 둘 다 있으면 안드로이드에서 **큰 설치 창**이 떠요. 스크린샷: `form_factor:"narrow"`, 예 780×1688 PNG, **가짜 데이터로** 찍기 |
| 6 | 서비스워커 | fetch 처리기 있음, 버전 올리면 캐시 이름도 바꾸기 |
| 7 | 문구 | 앱 이름·설명은 범용으로. 특정 기관 이름은 넣지 않기 |

## 2. 상태 판정 (`installState()`) — 순서대로
| 결과 | 조건 | 배너 | 누르면 |
|---|---|---|---|
| `app` | `matchMedia('(display-mode: standalone)')` 또는 `navigator.standalone` | 없음 | — |
| `desktop` | 아이폰·안드로이드 아님 | 없음 | — |
| `inapp` | UA에 KAKAOTALK·Slack·NAVER(inapp·Instagram·FBAN/FBAV/FB_IAB·Line/·BAND/·DaumApps·Telegram·everytimeApp, 또는 안드로이드 `; wv)`, 또는 아이폰인데 `Safari/` 없음 | 주황 「⚠️ 크롬(아이폰은 사파리)에서 열어야 설치돼요」 | 크롬으로 열기·사파리로 열기·주소 복사 창 |
| `other` | 아이폰: CriOS·FxiOS·EdgiOS·OPiOS·Whale / 안드로이드: SamsungBrowser·EdgA·OPR·Whale·YaBrowser·Firefox·UCBrowser·MiuiBrowser·HuaweiBrowser | 주황 (같음) | 같음 |
| `chrome` | 안드로이드 + `Chrome/` | 초록 「📲 홈 화면에 앱으로 설치」 | `beforeinstallprompt`를 받아 뒀으면 `prompt()`, 없으면 「⋮ → 앱 설치」 안내 창 |
| `safari` | 아이폰 사파리 | 초록 (같음) | 「공유(□↑) → 홈 화면에 추가」 안내 창 |

- 크롬으로 열기(안드로이드): `intent://{host}{path}#Intent;scheme=https;package=com.android.chrome;S.browser_fallback_url={인코딩한 주소};end`
- 사파리로 열기(아이폰 카톡): `kakaotalk://web/openExternal?url={인코딩한 주소}`
- 배너 ✕는 **이번에만 닫기**. 기록이 기기 안에만 있는 앱은 설치할 때까지 매번 보여요. 기록이 서버에 있는 앱이면 7일 숨김(학원 홈페이지 방식)을 써도 돼요.
- `appinstalled` 이벤트가 오면 배너를 없애요.
- 한계: 슬랙 안드로이드 등이 쓰는 **「앱 안 크롬 창」(Custom Tab)**은 진짜 크롬과 구별되지 않아요. 그래서 안내문에서 "복사해서 주소창에 붙여넣기"로 통일해요(6번).

## 3. 만들 것
| 번호 | 무엇 | 참고 |
|---|---|---|
| 3-1 | 상태 판정 + 배너 + 안내 창 3종 | `reference/install-guide.js` (프레임워크 없이 바로 쓰는 모듈). React면 학원 홈페이지 `InstallAppButton.tsx` 구조 참고 |
| 3-2 | 배너 모양 | `reference/install-guide.css`. 아래 탭바가 있으면 그 위에, 「＋」 버튼은 배너만큼 위로 올리기 |
| 3-3 | 설정 화면 | 「📲 설치 방법 보기」 버튼과 "지금 연 곳: 크롬/사파리/카카오톡…" 표시 |
| 3-4 | 「설치 먼저」 화면 | (기기 안 저장 앱만) 휴대폰에서 설치 전 처음 열면 PIN·첫 설정 대신 "먼저 설치하세요" + 「설치하지 않고 계속하기」 |
| 3-5 | CSP | `<meta http-equiv="Content-Security-Policy">`로 외부 스크립트 막기. 이 모듈은 외부 연결이 없어요 |

## 4. 테스트 (휴대폰 없이 8종)
`reference/install-test.cjs`를 앱에 맞게 고쳐서 실행해요 (Playwright). 결과는 모두 OK여야 해요.
안드로이드 크롬 · 아이폰 사파리 · 안드로이드 카톡 · 아이폰 카톡 · 안드로이드 슬랙 · 삼성 인터넷 · 아이폰 크롬 · 컴퓨터 → 배너 글자, 누르면 나오는 창, 「크롬으로 열기」·「사파리로 열기」 버튼, 주소 복사, ✕ 뒤 새로고침 시 다시 보이는지.
추가로 가짜 `beforeinstallprompt` 이벤트를 보내서 `prompt()`가 불리는지, `appinstalled` 뒤 배너가 사라지는지도 확인해요.

## 5. 문제 해결: "이미 설치되어 있습니다"인데 앱이 없을 때 (안드로이드)
| 순서 | 확인 |
|---|---|
| 1 | 휴대폰 크롬 주소창에 `chrome://webapks` → 이 앱이 목록에 있나? |
| 2 | 없으면: 설치 기록만 남고 실제 앱(WebAPK)을 못 만든 상태예요. 첫 배포 직후 설치할 때 흔해요 |
| 3 | 해결: manifest `id`를 새 고정값으로 **한 번만** 바꾸고 배포 → 크롬 바로가기 삭제 → 크롬 주소창에 주소 → 배너로 설치 → 다시 1번 확인 |
| 4 | 하지 말 것: 크롬 "사이트 데이터 삭제" 안내 (같은 도메인의 다른 앱 기록까지 지워져요) |
| 5 | 「바로가기 만들기」는 앱이 아니에요 (주소창이 보이고, 앱 목록에 없어요) |

## 6. 링크 공유 안내문 틀 (슬랙·카톡)
```
[앱이름] 설치 안내
① 아래 주소를 길게 눌러 복사하세요 (바로 누르지 말고)
   {앱 주소}
② 안드로이드는 「크롬」, 아이폰은 「사파리」를 열고 주소창에 붙여넣으세요
③ 화면 아래 「📲 홈 화면에 앱으로 설치」를 누르세요
   · 안드로이드: 「설치」 / 안 뜨면 오른쪽 위 ⋮ → 「앱 설치」
   · 아이폰: 아래 공유(□↑) → 「홈 화면에 추가」 → 추가
④ 「바로가기 만들기」는 고르지 마세요 (앱이 아니라 크롬 바로가기예요)
⑤ 이제 홈 화면의 아이콘으로 여세요
```

## 7. 기록 (AI 레디)
- 결정: 저장소 `metadata/decisions.md`에 ADR(고정 id, 배너 ✕ 방식, 브라우저 통일).
- 기계용 메타데이터: `reference/metadata.jsonld`를 복사해 앱 이름·주소·id·날짜만 바꿔요 (`schema:HowTo` + `prov`).
- 작업 기록: 사람용 표 + `prov:Activity` 한 줄.
