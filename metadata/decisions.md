# 결정 기록 (Decision Log)

새로 결정하면 아래에 번호를 이어서 적어요. 지난 결정을 바꿀 때는 지우지 말고 "바뀜: ADR-00N" 으로 남겨요.

| 번호 | 날짜 | 결정 | 이유 | 상태 |
|---|---|---|---|---|
| ADR-001 | 2026-10-16 | 기록은 휴대폰 IndexedDB 안에만 저장. 서버·구글 시트·클라우드 연동 없음 | 환자 관련 기록이 밖으로 나가지 않게 | 확정 |
| ADR-002 | 2026-10-16 | PIN(숫자 4~8자리)으로 만든 키(PBKDF2-SHA256 25만 번)로 AES-256-GCM 암호화. PIN 5번 틀리면 30초부터 늘어나는 대기 | 휴대폰을 잃어버려도 저장 파일만으로는 읽기 어렵게 | 확정 |
| ADR-003 | 2026-10-16 | 환자 이름·등록번호·생년월일 칸 없음. 7자리 이상 숫자·주민번호 모양이면 저장 전 경고 | 식별정보를 처음부터 받지 않기 | 확정 |
| ADR-004 | 2026-10-16 | 백업은 비밀번호(6자 이상, 두 번 입력) 없이는 만들 수도 열 수도 없음. 파일 이름은 영문 `handoff-backup_날짜_시각.json` | 내보낸 파일이 새도 읽히지 않게. 한글 파일 이름은 일부 브라우저에서 "download"로 바뀌어서 영문 사용 | 확정 |
| ADR-005 | 2026-10-16 | 글로 복사는 PIN 재확인 → 글 보여 주기 → 「복사하기」 두 단계 | 실수로 복사·유출 방지. 아이폰은 버튼을 직접 눌러야 복사가 허용됨 | 확정 |
| ADR-006 | 2026-10-16 | 자동 잠금 기본 3분, 앱 화면을 벗어나면 내용 가림. 쓰던 글은 암호화된 임시 저장으로 이어 쓰기 | 잠겨도 쓰던 글이 사라지지 않게 | 확정 |
| ADR-007 | 2026-10-16 | 분류 태그 = `procedures.jsonld`의 `appTag`. `tests/check-vocab.cjs`로 일치 확인 | 인계장·게임·문서가 같은 이름표를 쓰게(AI 레디) | 확정 |
| ADR-008 | 2026-10-16 | 백업 안 내용은 `@context`가 붙은 JSON-LD | 풀었을 때 바로 뜻이 통하는 데이터 | 확정 |
| ADR-009 | 2026-10-16 | 프레임워크 없이 HTML·CSS·JS 파일만. CSP로 외부 스크립트 차단 | 빌드 없이 GitHub 웹에서도 고칠 수 있고, 외부 코드가 기록에 닿지 않게 | 확정 |
| ADR-010 | 2026-10-16 | 인턴 술기 시뮬레이션 게임은 인계장 앱과 따로, 다음 단계로 | 근거 문서(내과 인계장 Word, 시술부위 그림)를 아직 다 읽지 못함 | 보류 |
| ADR-011 | 2026-10-16 | GitHub Pages: Deploy from a branch, `main` / `(root)`, Enforce HTTPS 켬, 커스텀 도메인 없음 | 빌드 없이 파일 그대로 배포. 암호화(Web Crypto)는 https에서만 작동. 따로 산 주소가 없으므로 기본 주소 사용 | 확정 |
| ADR-012 | 2026-10-16 | 작업이 끝날 때마다 기록 4곳을 함께 고침: `docs/worklog.md`(사람용) + `metadata/worklog.jsonld`(PROV-O, 기계용) + `docs/HANDOFF.md` + 결정이 있으면 `metadata/decisions.md` | 같은 설명을 반복하지 않고, AI가 작업 이력을 바로 읽을 수 있게(AI 레디) | 확정 |
