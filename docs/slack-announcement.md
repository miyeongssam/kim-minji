[인계장] 설치 안내

휴대폰 안에만 암호로 저장하는 인계장 앱이에요.
서버·클라우드로 내용이 나가지 않아요.

① 아래 주소를 길게 눌러 복사하세요. (슬랙에서 바로 누르지 말고)
https://miyeongssam.github.io/kim-minji/

② 안드로이드는 「크롬」, 아이폰은 「사파리」 주소창에 붙여넣으세요.

③ 화면 아래 「📲 홈 화면에 앱으로 설치」를 누르세요.
· 안드로이드: 「설치」 (안 뜨면 오른쪽 위 ⋮ → 「앱 설치」)
· 아이폰: 아래 공유(□↑) → 「홈 화면에 추가」 → 추가
「바로가기 만들기」는 고르지 마세요.

④ 홈 화면의 「인계장」 아이콘으로 열고 PIN을 정하세요.
처음 한 번 나오는 복구 코드는 종이에 적어 두세요.

환자 이름·등록번호·생년월일은 적지 말고 병실·침상 번호로 구분해 주세요.
