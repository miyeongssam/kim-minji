## 7. 꼭 지키는 규칙 (앱)

| 번호 | 규칙 |
|---|---|
| 1 | 기록은 휴대폰 IndexedDB 안에만 암호화해서 저장해요. 서버·구글 시트·드라이브·노션·외부 CDN을 연결하지 않아요 |
| 2 | 환자 이름·등록번호·생년월일·사진 칸은 만들지 않아요. 7자리 이상 숫자가 있으면 저장 전에 경고해요 |
| 3 | 백업은 비밀번호 없이 만들거나 열 수 없어요. 글로 복사는 PIN 재확인 후에만 돼요 |
| 4 | PIN·복구 코드는 어디에도 저장하지 않아요. 잠금 방식은 vault v2(데이터 키를 PIN·복구 코드로 각각 감싸 둠)예요 |
| 5 | PIN·비밀번호 칸은 `type=password`를 쓰지 않아요 (구글 비밀번호 관리자 저장 방지) |
| 6 | 고칠 때마다 버전 3곳(app.js·sw.js·index.html)을 올리고 → 테스트 4종 → 기록 4곳 → PR 링크를 첫 줄에 드려요 |
| 7 | 링크 안내: "복사해서 안드로이드는 크롬, 아이폰은 사파리 주소창에 붙여넣기" |

## 8. 주요 결정 (자세한 내용은 `metadata/decisions.md` ADR-001~028)

| 번호 | 결정 | 이유 |
|---|---|---|
| 1 | 본인 인증으로 PIN 알려 주기는 하지 않고, 복구 코드 사용 | 본인 인증은 PIN이나 열쇠를 서버에 맡겨야 해서 |
| 2 | 복구 코드는 종이 + (선택) 내 메일로 보내기 | 같은 휴대폰 메모장은 피하기 |
| 3 | 새벽 자동 백업은 하지 않고, 7일 지나면 앱을 열 때 알림 | 웹 앱은 꺼져 있을 때 파일을 만들 수 없어서 |
| 4 | 앱을 지우고 다시 깔아도 PIN은 초기화되지 않음 (안드로이드) → 앱 안 「PIN을 잊었어요」 | 크롬 저장 공간에 옛 기록이 남아서 |
| 5 | 안드로이드 "이미 설치됨인데 앱 없음" → `chrome://webapks` 확인 → manifest id 한 번만 바꿔서 해결 | 같은 주소의 다른 최과학 앱 기록을 지우지 않으려고 |
| 6 | 공휴일은 공식 발표(우주항공청 월력요항, 2026.4.28 규정 개정: 노동절·제헌절)만 근거로 | 날짜를 지어내지 않으려고 |
| 7 | 앱 문구는 범용 「병원 인계장」 | 다른 병원에서도 쓸 수 있게 |

## 10. 다른 레포·대화에서 다시 쓸 것
- **홈 화면 설치:** "홈 화면 설치 넣어 줘"라고 말하면 `pwa-install-guide` 스킬이 순서대로 처리해요. 순서는 manifest 점검 → 배너 → 8종 테스트 → 안내문 → 기록이에요.
- **AI 레디 기록:** 작업마다 사람용 표 + `prov:Activity` + HANDOFF + ADR을 남겨요. 이 레포의 `CLAUDE.md` 「기록 규칙」을 그대로 복사해 쓰면 돼요.
- **참고한 다른 레포:** `choisci-homepage`의 `InstallAppButton.tsx`(설치 배너 원본), `choigwahak-science`의 앱 manifest들(비교용).

## 11. 일하는 방식 메모 (미영쌤)
- 계획을 먼저 보고 "수정해 / 만들어 / 시작해" 뒤에 진행해요. 선택지는 번호와 추천안으로 받아요.
- PR은 답변 맨 위 첫 줄에 누를 수 있는 주소로 받아요. 합치는 건 미영쌤이 해요.
- 복잡한 기능보다 단순한 안내를 좋아해요 (예: 슬랙 감지 기능 대신 "복사해서 붙여넣기").
- 기록은 늘 AI 레디(사람용 + 기계용)로 남겨요.
