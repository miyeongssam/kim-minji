민지야, 인계장 앱 만들 준비 해 뒀어.
깃허브 저장소 kim-minji를 네 Claude Code 세션에 연결해 놨어.
이제 그 대화창에서 Claude한테 말로 시키면 앱을 만들어 줘.

[1. 앱이 어떻게 생겼는지]
- 깃허브(kim-minji)에는 앱 껍데기(화면·버튼)만 들어가.
- 네가 앱에 적는 인계 내용은 전부 네 휴대폰 안에만, 암호로 잠겨서 저장돼.
- 깃허브나 인터넷으로 내용이 나가지 않아.
- 저장소는 공개로 두지만 껍데기만 있어서 누가 봐도 인계 내용은 볼 수 없어.

[2. 꼭 지킬 것 ★]
- 인계장은 절대로 구글 시트·구글 드라이브·아이클라우드·노션 같은 클라우드에 올리지 마.
- 인계장은 이 앱 안에만 저장해.
- 휴대폰 메모장은 쓰지 마. 아이폰 메모는 아이클라우드, 삼성 노트는 삼성 클라우드에 자동으로 올라갈 수 있어.
- 내보내기 파일을 만들 때나 카톡으로 보낼 때는 반드시 비밀번호를 걸어. (앱이 비밀번호 없이는 파일을 안 만들어)
- 비밀번호는 파일과 같은 메시지로 보내지 말고, 말로 따로 알려 줘.
- 환자 이름·등록번호·생년월일처럼 누군지 알 수 있는 내용은 적지 마. 병실·침상 번호로 구분해.
- 「글로 복사」한 글은 꼭 필요한 곳에만 붙여 넣고, 단톡방에는 올리지 마.
- 반드시 「홈 화면에 추가」로 설치해서 써. (설치 안 하면 아이폰에서 내용이 지워질 수 있어)
- 설치한 뒤에는 홈 화면 아이콘으로만 열어. 아이폰은 사파리에서 쓰던 내용이 설치한 앱으로 옮겨지지 않아.
- 브라우저 기록·사이트 데이터를 지우거나 앱을 삭제하면 내용도 지워져.
- PIN을 잊으면 아무도 되살릴 수 없어. 그래서 백업이 중요해.

[3. Claude Code한테 말하는 요령]
① "먼저 계획만 보여 줘"라고 하고, 계획을 보고 "좋아, 만들어"라고 해.
② 한 번에 하나씩 요청해. (예: 오늘은 쓰기 화면, 내일은 백업)
③ 고칠 게 생기면 모아서 한 번에 말해.
④ 다 만들면 "휴대폰 화면으로 확인했어?"라고 물어봐.
⑤ 모르는 말이 나오면 "쉽게 다시 설명해 줘"라고 하면 돼.
⑥ 새 대화를 열면 "docs/HANDOFF.md 읽고 이어서 하자"라고 말해. 그러면 처음부터 다시 설명하지 않아도 돼.

[4. 첫 메시지로 보낸 글 (이 요청으로 1.0.0이 만들어졌어)]
kim-minji 저장소에 병원 인계장 앱을 만들고 싶어. 먼저 계획만 보여 줘.
- 휴대폰에 설치해서 쓰는 앱(PWA), 한국어
- 내용은 휴대폰 안에만 저장. 서버·구글 시트·클라우드에 절대 올리지 않기
- 앱을 열 때 비밀번호(PIN)
- 인계장 쓰기·고치기·날짜별 보기·검색
- 백업 내보내기/가져오기: 비밀번호를 넣어야만 파일이 만들어지고 열리게(비밀번호 없이는 내보내기 안 되게)
- 글로 복사할 때도 비밀번호를 한 번 더 확인
- 환자 이름·등록번호 칸은 만들지 않기
- 다 만들면 main에 합치는 PR을 만들고, GitHub Pages 켜는 방법을 알려 줘

앞으로 고칠 때는 이렇게 말하면 돼:
"인계장 앱 써 보니까 고칠 게 있어. 먼저 계획만 보여 줘.
① ……
② ……"

[5. 다 만든 뒤]
- PR은 Claude가 만들어 둬. PR이 만들어지면 나한테 말해 줘. 내가 합치고 Pages를 켜 줄게.
- 그다음 휴대폰에서 아래 주소를 열고 「홈 화면에 추가」 하면 끝이야.
  https://miyeongssam.github.io/kim-minji/
- 아이폰: 사파리로 열기 → 아래쪽 공유 버튼(□↑) → 홈 화면에 추가
- 안드로이드: 크롬으로 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치)

[6. 백업하는 법]
- 앱 「설정」 → 「백업 내보내기」 → 백업 비밀번호 두 번 입력(6자 이상) → 「잠긴 백업 파일 만들기」 → 「휴대폰에 저장」.
- 파일 이름은 handoff-backup_날짜_시각.json 이야.
- 파일은 휴대폰 안에만 둬. (아이폰: 파일 앱 「나의 iPhone」, 안드로이드: 다운로드 폴더)
  아이폰은 「iCloud Drive」가 아니라 「나의 iPhone」을 골라.
- 다음 사람한테 넘길 때만 카톡으로 파일을 보내고, 비밀번호는 따로 말로 알려 줘.
- 백업 비밀번호는 앱 PIN과 달라도 돼. 둘 다 잊지 마.
- 일주일에 한 번은 백업해 둬. (앱이 일주일 지나면 알려 줘)

[7. 공부·업무 자료 활용하기 (알아 두면 좋은 배경 지식)]
- 환자 정보·개인정보가 없는 학술 자료(논문, PPT, 가이드라인, 교과서 내용 등)는 Claude Code 대화창에 바로 줘도 돼.
- 공개 링크(누구나 열 수 있는 주소)는 링크만 붙여 넣으면 Claude가 읽고 정리해 줘.
- 로그인해야 열리는 링크(병원 내부망)는 못 읽어.
- 구글 드라이브를 Claude에 연결해 둔 계정이면 비공개 파일도 읽을 수 있어.
  단, Word 원본은 글자가 안 나올 수 있어서 드라이브에서 「파일 → Google 문서로 저장」 해 두면 잘 읽어.
- 그 밖에는 파일(PPT·PDF)을 대화창에 직접 올려.
  큰 파일(수십 MB)은 첨부가 안 돼. PDF로 바꾸거나 나눠서 올려.
- 이렇게 말하면 돼:
  "이 링크 읽고 핵심만 표로 정리해 줘"
  "이 PPT 내용으로 인계장 앱에 넣을 체크리스트 만들어 줘"
- 단, 환자 이름·등록번호·생년월일·사진·검사 결과가 조금이라도 들어 있는 자료는 절대 올리지 마.
