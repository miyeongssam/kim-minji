민지야, 인계장 앱 준비 다 됐어.
앱 주소: https://miyeongssam.github.io/kim-minji/

[1. 앱이 어떻게 생겼는지]
- 깃허브(kim-minji)에는 앱 껍데기(화면·버튼)만 있어. 공개 저장소지만 인계 내용은 없어.
- 네가 적는 인계 내용은 전부 네 휴대폰 안에만, 암호로 잠겨서 저장돼.
- 인터넷이나 서버로 내용이 나가지 않아.

[2. 설치하는 법 ★ 링크는 꼭 복사해서]
① 주소를 길게 눌러 복사해. (카톡·문자·슬랙에서 바로 누르지 마)
② 안드로이드는 「크롬」, 아이폰은 「사파리」를 열고 주소창에 붙여넣어.
③ 화면 아래 「📲 홈 화면에 앱으로 설치」를 눌러.
   · 안드로이드: 「설치」 (안 뜨면 오른쪽 위 ⋮ → 「앱 설치」)
   · 아이폰: 아래 공유 버튼(□↑) → 「홈 화면에 추가」 → 추가
④ 「바로가기 만들기」는 고르지 마. 앱이 아니라 크롬 바로가기야.
⑤ 홈 화면의 「인계장」 아이콘으로 열고, 거기서 PIN을 정해.
   (아이폰은 사파리에서 먼저 PIN을 정하면 그 내용이 앱으로 안 옮겨져. 꼭 설치한 앱에서 시작해)
- 배너가 「⚠️ 크롬(사파리)에서 열어야 설치돼요」로 뜨면 지금 카톡 같은 다른 화면이라는 뜻이야. 배너를 누르고 「크롬으로 열기」나 「주소 복사」를 써.

[3. PIN과 복구 코드]
- PIN은 숫자 4~8자리야. 앱을 열 때마다 같은 PIN을 넣어. (3분 동안 안 쓰면 자동으로 잠겨)
- PIN을 정하면 「복구 코드」가 딱 한 번 나와. 종이에 적어 두거나 「메일로 보내기」로 내 메일에 보내 둬.
  같은 휴대폰 메모장에는 적지 마. 휴대폰을 잃어버리면 같이 보여.
- PIN을 잊으면: 잠금 화면 「PIN을 잊었어요」 → 복구 코드 입력 → 새 PIN. 기록은 그대로야.
- 복구 코드까지 잃어버리면: 「모두 지우고 새로 시작」 → 새 PIN → 설정 → 백업 가져오기로 마지막 백업을 되살려.
- 앱을 지우고 다시 깔아도 PIN은 안 바뀌어. 꼭 「PIN을 잊었어요」를 써.
- PIN이나 백업 비밀번호를 구글 비밀번호 관리자에 저장하지 마. (앱이 저장 창을 띄우지 않게 해 뒀어)

[4. 쓰는 법]
- 「＋ 새 인계」 → 날짜·병동·병실침상·요약·분류·내용·할 일 → 저장
- 「날짜별」: 한 달 달력에서 날짜를 누르면 아래에 그날 인계가 나와. ◀ ▶나 옆으로 밀면 달이 넘어가.
  칸의 숫자는 인계 건수(주황 = 아직 안 끝난 할 일), 빨간 날은 일요일·공휴일이야.
- 빈 날짜에서 「↪ 인계 이어받기」를 누르면 전날 인계 중 안 끝난 할 일만 가져와.
- 🔍 검색: 낱말로 찾기, 「끝나지 않은 할 일만」 보기
- 📋 글로 복사: PIN을 한 번 더 넣어야 복사돼. 꼭 필요한 곳에만 붙여 넣고, 단톡방에는 올리지 마.

[5. 꼭 지킬 것 ★]
- 환자 이름·등록번호·생년월일처럼 누군지 알 수 있는 내용은 적지 마. 병실·침상 번호로 구분해.
  (등록번호처럼 보이는 숫자를 쓰면 앱이 한 번 물어봐)
- 인계장은 구글 시트·드라이브·아이클라우드·노션 같은 클라우드에 올리지 마. 이 앱 안에만 저장해.
- 휴대폰 메모장도 쓰지 마. 아이폰 메모는 아이클라우드, 삼성 노트는 삼성 클라우드에 자동으로 올라갈 수 있어.
- 브라우저 기록·사이트 데이터를 지우면 내용도 지워져.

[6. 백업]
- 설정 → 「백업 내보내기」 → 백업 비밀번호 두 번(6자 이상) → 「잠긴 백업 파일 만들기」 → 「휴대폰에 저장」
- 백업한 지 7일이 지나면 앱을 열 때 「지금 백업할까요?」가 떠. 비밀번호 넣고 저장하면 끝이야. (「나중에」는 다음 날 다시 물어봐)
- 새벽에 혼자 자동 백업되지는 않아. 웹 앱은 꺼져 있을 때 파일을 만들 수 없어서야.
- 파일(handoff-backup_날짜_시각.json)은 휴대폰 안에만 둬. 아이폰은 파일 앱 「나의 iPhone」(iCloud Drive 말고), 안드로이드는 다운로드 폴더.
- 다음 사람한테 넘길 때만 카톡으로 파일을 보내고, 백업 비밀번호는 같은 메시지 말고 말로 따로 알려 줘.
- 새 휴대폰으로 옮길 때: 새 휴대폰에 설치 → PIN 정하기 → 설정 → 백업 가져오기 → 「바꾸기」

[7. Claude Code한테 말하는 요령]
① "먼저 계획만 보여 줘"라고 하고, 계획을 보고 "좋아, 만들어"라고 해.
② 한 번에 하나씩 요청해. 고칠 게 생기면 모아서 한 번에 말해.
③ 다 만들면 "휴대폰 화면으로 확인했어?"라고 물어봐.
④ 모르는 말이 나오면 "쉽게 다시 설명해 줘"라고 하면 돼.
⑤ 새 대화를 열면 "docs/HANDOFF.md 읽고 이어서 하자"라고 말해. 처음부터 다시 설명하지 않아도 돼.
⑥ 고칠 때 예시: "인계장 앱 써 보니까 고칠 게 있어. 먼저 계획만 보여 줘. ① …… ② ……"
⑦ Claude가 PR을 만들면 링크를 맨 위에 줘. 그 링크를 나한테 보내 주면 내가 합칠게.

[8. PPT·PDF 자료를 Claude 대화창에서 쓰는 법]
- 쓸 수 있는 자료: 환자 정보가 없는 학술·교육 자료 (논문, 강의 PPT, 가이드라인, 교과서, 인계 매뉴얼)
- 쓰면 안 되는 자료: 환자 이름·등록번호·생년월일·사진·검사 결과가 조금이라도 들어 있는 것

방법 1) 대화창에 바로 올리기 (작은 파일)
  · 클립(📎) 버튼이나 끌어다 놓기로 PPT·PDF를 올려.
  · 수십 MB가 넘으면 안 올라가. 그럴 땐 필요한 부분만 PDF로 저장하거나 나눠서 올려.
  · 사진·그림이 중요한 자료(물품 사진, 부위 그림)는 이 방법이 가장 확실해.

방법 2) 구글 드라이브로 (큰 파일, 글 위주)
  · 드라이브에 올리고 "드라이브의 ○○ 파일 읽어 줘"라고 파일 이름을 말해.
  · Claude에 구글 드라이브가 연결된 계정이어야 해.
  · Word(.docx)는 글이 안 읽힐 수 있어. 드라이브에서 열고 「파일 → Google 문서로 저장」 한 뒤 그 파일 이름을 말해.
  · 드라이브로는 글만 읽혀. 사진·그림은 방법 1로 따로 올려.

방법 3) 공개 링크
  · 누구나 열 수 있는 주소면 링크만 붙여 넣어도 돼. 로그인해야 열리는 링크(병원 내부망)는 못 읽어.

이렇게 말하면 돼:
  "이 PPT 읽고 핵심만 표로 정리해 줘"
  "이 PDF에서 ABGA 순서만 뽑아서 체크리스트로 만들어 줘"
  "이 자료로 인계장 앱 분류 태그에 넣을 술기 목록 만들어 줘"
