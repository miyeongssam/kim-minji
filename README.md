# 인계장 (kim-minji)

휴대폰에 설치해서 쓰는 인턴 인계장 앱이에요. **기록은 휴대폰 안에만 암호로 잠겨서 저장**되고, 이 저장소에는 앱 껍데기(화면·버튼)만 있어요.

앱 주소: https://miyeongssam.github.io/kim-minji/

## 사용법

| 번호 | 하고 싶은 것 | 방법 |
|---|---|---|
| 1 | 설치 | 링크를 복사해서 **안드로이드는 크롬, 아이폰은 사파리** 주소창에 붙여넣고 열기 → 아래 「📲 홈 화면에 앱으로 설치」 배너 누르기 → 안내대로 설치 → 홈 화면 「인계장」 아이콘으로 열기. 「바로가기 만들기」는 고르지 않기 |
| 2 | 처음 PIN 정하기 | 처음 열면 숫자 4~8자리 PIN을 두 번 입력 → 시작하기 |
| 3 | 인계 쓰기 | 「＋ 새 인계」 → 날짜·병동·병실침상·요약·분류·내용·할 일 → 저장 |
| 4 | 고치기·지우기 | 카드 누르기 → ✏️ 고치기 / 🗑 지우기 |
| 5 | 할 일 체크 | 카드 안에서 할 일 네모 누르기 |
| 6 | 날짜별 보기 | 한 달 달력에서 날짜를 누르면 아래에 그날 인계 목록. ◀ ▶ 또는 옆으로 밀어서 달 넘기기, 「2026년 10월」 글자를 누르면 달 고르기. 칸의 숫자는 인계 건수(주황 = 남은 할 일), 빨간 날은 일요일·공휴일 |
| 7 | 전날 인계 이어받기 | 빈 날짜에서 「↪ ○월 ○일 인계 이어받기」 (끝나지 않은 할 일만) |
| 8 | 검색 | 🔍 검색 → 낱말 입력 / 「끝나지 않은 할 일이 있는 것만」 체크 |
| 9 | 글로 복사 | 카드 → 📋 글로 복사 (또는 날짜 화면 「이 날 전체 글로 복사」) → PIN 한 번 더 → 복사하기 |
| 10 | 백업 | ⚙️ 설정 → 백업 비밀번호 두 번 → 잠긴 백업 파일 만들기 → 휴대폰에 저장 |
| 11 | 백업 가져오기 | ⚙️ 설정 → 파일 고르기 → 백업 비밀번호 → 합치기(더하기) 또는 바꾸기(새 휴대폰) |
| 12 | 잠금 | 오른쪽 위 🔒 잠금. 자동 잠금 시간은 설정에서 |
| 13 | PIN 바꾸기 | ⚙️ 설정 → 지금 PIN, 새 PIN 두 번 |

## 지키는 규칙

- 환자 이름·등록번호·생년월일 칸이 없어요. 등록번호처럼 보이는 숫자를 쓰면 저장 전에 알려 줘요.
- 백업 파일은 비밀번호 없이는 만들 수도, 열 수도 없어요.
- PIN을 잊으면 아무도 되살릴 수 없어요. 일주일에 한 번 백업하세요.
